**Under the native engine, Reanimated 4.7+ (with Worklets 0.9+) is Reanimated's own test mock.** `react-native-reanimated` resolves to `react-native-reanimated/mock`, as a Jest suite gets it with `jest.mock('react-native-reanimated', () => require('react-native-reanimated/mock'))`. No action needed; `presets: { reanimated: false }` turns it off. Older Reanimated or Worklets, and the mock engine, keep the hand-written preset.

- The hand-written preset lacked 104 of the mock's names, including `interpolateColor`, `clamp`, `Keyframe`, `useScrollOffset`, `Extrapolate`, most layout-animation presets, `Easing.exp`/`bounce`/`elastic`, `withReanimatedTimer` and `getAnimatedStyle`. It also called animation callbacks with `{ finished, current }` where Reanimated passes `true`.
- The mock loads the real package through the Jest resolvers Reanimated and Worklets ship. The engine consults those resolvers only for those two packages' own files, so pnpm store neighbours and `react-native-worklets-core` are unaffected.
- Behaviour that now matches Jest with Reanimated's mock: a `useSharedValue` is a new `{ value }` each render; `makeMutable(x)` returns `x`; `cancelAnimation`, `scrollTo` and the other no-ops are plain functions, not `vi.fn`; `withReanimatedTimer` and `advanceAnimationByTime` need `jestCompatSetup`.
- Under the native engine the worklets preset's module is Worklets' own test mock (`lib/module/mock.js`), so a test's import of `react-native-worklets` and Reanimated's require of it get one instance. It is built as each test file is set up, as a Jest suite installs it, so the `requestAnimationFrame` it sets never replaces one that fake timers installed. Its `runOnJS`, `runOnUI`, `scheduleOnRN` and `scheduleOnUI` run their worklet on a later tick, as under Jest, so a test that reads the result awaits it (`await waitFor(...)`).
- The real package costs no extra per-file loading. The module graphs of both mocks, with the packages they depend on as their own, are precompiled into a second registry layered on React Native's, built and cached with it. A file that imports Reanimated loads none of their modules through Node and runs only the ones it reaches. Its Node module loads stay within two, and its resolutions within four, of a file using the preset, stock and under `hotRuntime`, and it takes about as long.
