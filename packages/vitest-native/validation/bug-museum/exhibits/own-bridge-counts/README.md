# The require bridge's cost on a monorepo-shaped graph

- **Class:** ownership
- **Source:** ownership track A3, decision condition 8 (counts on an S1 shape)
- **Fixed by:** open (ownership track A3, under `experimental.ownershipModel: 'resolution'`)
- **Needs:** nothing beyond this repository's install

## The bug

A React Native workspace library (Node loads it) requires a store whose graph is 150
project modules (generated by `graph.ts`), before the test imports it: on main, Node
compiles a second copy of all 150.

## Expected behaviour

Counted, not timed:
- Node first: 150 evaluations, 150 + 1 fetches (one per module, one for the installed
  package every module imports; the builtin needs none), one helper thread; the import after
  it adds nothing.
- Vite first: no thread, no fetch.

## Control

None: the counters exist only with the bridge.
